## Работа с виртуальными окружениями

Для выполнения работ мы будем использовать стандартный модуль [`venv`](https://docs.python.org/3/library/venv.html), появившийся с версии 3.3 и предназначенный для создания и управления изолированными (виртуальными) окружениями. `venv` позволяет заключить в отдельный каталог необходимые версии python-пакетов и использовать только их. Используя `venv`, вы можете устанавливать свежие версии пакетов из [Python Package Index](https://pypi.python.org/pypi), при этом не получая проблем с совместимостью версий загруженных пакетов и тех, что уже имеются в системе.

Создадим отдельный каталог `~/.virtualenvs` (некоторые редакторы, например, [VSCode](https://code.visualstudio.com/), по умолчанию полагаются именно на такое название и расположение каталога при поиске доступных интерпретаторов) для виртуальных окружений и новое окружение с именем `cs102`:

```python
$ mkdir ~/.virtualenvs
$ python -m venv ~/.virtualenvs/cs102
$ which python
~/.pyenv/shims/python
$ source ~/.virtualenvs/cs102/bin/activate # Scripts вместо bin, если вы на Windows
(cs102) $ which python
~/.virtualenvs/cs102/bin/python
(cs102) $ deactivate
$ which python
~/.pyenv/shims/python
```

> **Знак `$` означает приглашение к вводу команд и копировать его и все, что до него, в терминал не нужно.**

Для быстрого переключения на нужное виртуальное окружение рекомендуется добавить следующую функцию в файл `~/.bashrc` (если у вас MacOS, то `~/.zshrc`), который хранится в корневом каталоге вашего пользователя. Обычно этот файл является скрытым, поэтому может потребоваться сделать все скрытые файлы видимыми, чтобы этот файл найти.

Если такого файла в вашей системе еще нет, то его можно создать так:

```python
$ echo "" >> ~/.bashrc  # или ~/.zshrc для MacOS
```

Теперь файл можно увидеть и отредактировать. Добавьте в него функцию `workon`, которая будет отвечать за запуск виртуального окружения. Обратите внимание, действия выполняются в этой функции и сравните их с теми, что вы выполнили выше для создания виртуального окружения. Сохраните изменения в файле `~/.bashrc` и выполните команду `. ~/.bashrc` (или `source ~/.bashrc`), чтобы функция стала доступна в текущем сеансе.

Для Ubuntu и MacOS:

```python
function workon() {
    if test -z "$1" ; then
        echo "Specify the name of the virtual environment"
    elif test ! -f "$HOME/.virtualenvs/$1/bin/activate" ; then
        echo "Environment doesn't exist"
    else
        deactivate 2> /dev/null
        source "$HOME/.virtualenvs/$1/bin/activate"
    fi
}
```

Для Windows:

```python
function workon() {
    if test -z "$1" ; then
        echo "Specify the name of the virtual environment"
    elif test ! -f "$HOME/.virtualenvs/$1/Scripts/activate" ; then
        echo "Environment doesn't exist"
    else
        deactivate 2> /dev/null
        source "$HOME/.virtualenvs/$1/Scripts/activate"
    fi
}
```

> Файл `.bashrc` можно открыть командой `sudo nano ~/.bashrc` на Ubuntu и MacOS (или любом графическом текстовом редакторе). На Windows файл можно найти в корневом каталоге и открыть через текстовый редактор.

Для примера в созданном виртуальном окружении установим следующие пакеты: [black](https://github.com/psf/black) (для автоматического форматирования кода), [isort](https://github.com/timothycrosley/isort) (для сортировки импортов, т.е., имен подключаемых модулей), [mypy](http://mypy-lang.org/) (для проверки типов) и [pylint](https://www.pylint.org/) (статический анализатор кода для выявления потенциальных проблем синтаксиса):

```python
$ workon cs102
(cs102) $ pip freeze
# Установленных пакетов нет
(cs102) $ python -m pip install black isort mypy pylint
(cs102) $ pip freeze
black==26.3.1
isort==5.13.2
mypy==1.11.2
pylint==3.3.0
...
```

В этом примере мы использовали [pip](https://docs.python.org/3.5/installing/index.html) для установки новых пакетов. Иногда устанавливаемый пакет требует наличия других пакетов для своей работы, обычно эти пакеты устанавливаются автоматически (говорят «по зависимостям»). Но может возникнуть ситуация, когда вам придется вручную установить нужную библиотеку. Если вы не знаете как это сделать, то поищите ответ на stackoverflow.com, скорее всего кто-то уже столкнулся с той же проблемой, что и вы. Рекомендуется сделать это ДО попыток решить проблему через генеративную нейросеть, чтобы сократить число устраняемых в будущем проблем с зависимостями.

Все изменения, которые будут происходить с вашими работами, могут храниться локально (у вас на компьютере), а могут и удаленно, так, что вы всегда сможете продолжить работу над своим проектом. Поэтому вам необходимо зарегистрироваться на https://github.com.

После выполнения команды `git clone` будет создан каталог с именем `cs102-2026`. Для быстрого перехода в этот каталог добавим alias в ваш `.bashrc` или `.zshrc`, для этого откройте терминал и выполните следующие команды:

```python
$ echo 'alias gocs102="cd /путь/к/каталогу/cs102-2026"' >> ~/.bashrc
$ . ~/.bashrc
$ gocs102
$ pwd
/путь/к/каталогу/cs102-2026
```

Теперь при вводе команды `gocs102` вы всегда и из любого расположения будете попадать в каталог `cs102-2026`, где расположен ваш репозиторий.

## Выбор редактора кода

Вам будет нужен редактор кода. Это может быть «простой» текстовый редактор с подсветкой синтаксиса и дополнительно устанавливаемыми расширениями, например, [VSCode](https://code.visualstudio.com/), [Vim](http://www.vim.org/), [Atom](https://atom.io/), [SublimeText](https://www.sublimetext.com/) или же полноценная среда разработки [PyCharm](https://www.jetbrains.com/pycharm/download/). Рекомендуется попробовать разные редакторы, потратив некоторое время на ознакомление с их возможностями и чтение документации. Использовать агентные редакторы кода вроде `Cursor` при выполннеии лабораторных работ не рекомендуется.

Найдите в вашем локальном репозитории (папке с названием cs102-2026) файл `hello_world.py` , найдите в нем ошибки синтаксиса и исправьте их. Если не получается найти шибку, можно обратиться за помощью к преподавателю практики. Оценивается на данном этапе внесение правки в файл, а не самостоятельное устранение ошибок. После внесения правок откройте терминал и выполните следующие команды:

```python
$ isort homework00/hello_world.py
$ black -l 120 homework00/hello_world.py
$ mypy homework00/hello_world.py
$ pylint homework00/hello_world.py
```

Если какая-либо из команд сообщает вам об ошибках, ваша задача – исправить эти ошибки. `pylint` будет печатать рекомендации по оптимизации вашего кода, настоятельно рекомендуется последовать этим рекомендациям и получить рейтинг кода не менее 8.00.

Когда все ошибки будут устранены выполненные вами изменения в файле `hello_world.py` необходимо зафиксировать и отправить на проверку:

```python
$ git checkout -b homework00
$ git add homework00/hello_world.py
$ git commit -m "Исправлены ошибки"
$ git push origin homework00
```

После выполнения последней команды ваши изменения окажутся на сервере. Вы увидите, что теперь можете сделать запрос на изменения (Compare & pull request), а также наличие ветки `homework00`:
